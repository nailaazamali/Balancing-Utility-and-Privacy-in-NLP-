# Human evaluation

This folder contains the materials that match the human-evaluation procedure described in the final paper:

- `annotation_protocol.md`: the three review criteria;
- `annotation_template.csv`: a blank annotation format.

The paper reports 450 reviewed counterfactuals. The two annotators initially agreed on 412 cases (91.6%), with Cohen's κ = 0.831. The 38 disagreements were resolved through discussion. The aggregate values are stored in `../results/human_evaluation_summary.csv`.

The original row-level annotations are not included in this repository. Older spreadsheets used during exploratory versions of the study have been removed because they do not represent the final XAIStrengthNLP and XAILeakageNLP definitions.
