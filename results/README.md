# Results

The following CSV files contain the aggregate results reported in the paper:

- `main_summary.csv`;
- `feasibility_summary.csv`;
- `fixed_epsilon_ablation.csv`;
- `baseline_comparison.csv`;
- `robustness_summary.csv`;
- `human_evaluation_summary.csv`.

`archived_run_data_summary.csv` describes the separate 700/609/100/450 archived runnable experiment.

The exact row-level paper split is not included, so the paper result CSVs are stored as reported aggregate values rather than recomputed from released paper-level records.

New experiment outputs are written under `outputs/` and do not overwrite these files.
